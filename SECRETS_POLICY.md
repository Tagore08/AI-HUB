# Secrets Policy & Data Sensitivity
Last reviewed: 2026-10-02

## Forbidden Items
The following must **NEVER** be stored in AI-HUB:
- API keys
- Passwords
- Access tokens
- SSH keys (.pem, id_rsa, etc.)
- Authentication cookies
- Government ID numbers (SSN, etc.)
- Bank or credit card details

## Data Sensitivity Guide
- **PUBLIC**: Safe to share anywhere, including open internet.
- **PRIVATE**: Fine for paid AI providers with strict privacy agreements. Think carefully before pasting into free-tier cloud AI models.
- **LOCAL-ONLY**: Strictly confidential. Never paste into any cloud AI service. Keep solely on your local machine.
