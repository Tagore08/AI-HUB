# AI-HUB

A personal AI context hub — rules, prompts, and project templates for working with multiple LLMs (ChatGPT, Claude, Gemini, Codex, local models, coding agents) without rebuilding context every session.

## What's here

- `INSTRUCTIONS/` — master rules, permissions, portable preamble (paste into any chat app)
- `PROMPTS/` — task templates and role prompts
- `SCRIPTS/` — helper scripts for bundling context
- `PROJECTS/TEMPLATES/` — starter structure for new projects
- `AGENTS.md` — table of contents that AI agents read first

## Purpose

This is published so others can borrow the structure. Nothing here is maintained for external users. It's a personal setup that happens to be public.

## Not included

Personal projects, private notes, learning logs, and outputs stay in a separate private repo.
