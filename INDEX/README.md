# AI-HUB Index

**Last reviewed**: 2026-10-03  
**Scope**: High-level registries, keyword lookup maps, and cross-project cataloging.

---

## Purpose
The `INDEX/` directory holds lightweight indices that allow agents and users to locate specific topics, prompts, tools, or projects without performing recursive full-text scans across the entire workspace.

---

## Contents & Conventions
- Indices should be concise markdown files or structured JSON indexes.
- Update index entries when adding new permanent knowledge entries or standard templates.
- Avoid tracking transient build artifacts or local project run states here.
