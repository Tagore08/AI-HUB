# Project Agent Guide

**Scope**: Rules and context specific to this project. Overrides global defaults.

## Operating Principles
1. Read `README.md` and `GOALS.md` before taking action.
2. Check `CURRENT_STATE.md` to understand ongoing status and recent milestones.
3. Check `TODO.md` for prioritized tasks.
4. Record major architectural shifts and choices in `DECISIONS.md`.
5. Keep changes focused on the project's defined scope.

## Context Folders
- `context/active/`: Relevant active references and inputs.
- `context/archive/`: Deprecated or completed reference materials.

*Note: For tiny projects, use only `README.md`, `GOALS.md`, `CURRENT_STATE.md`, and `TODO.md`.*
