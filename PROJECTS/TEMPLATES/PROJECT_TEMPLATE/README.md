## File Structure & Usage Guide
- `AGENTS.md` — Project-specific AI guidelines and constraints.
- `GOALS.md` — High-level outcomes and success criteria.
- `REQUIREMENTS.md` — Functional and non-functional specifications.
- `ARCHITECTURE.md` — System design, components, and data flow.
- `PLAN.md` — Implementation phases and work breakdown.
- `CURRENT_STATE.md` — Running log of current status and milestones.
- `DECISIONS.md` — Architecture decisions log.
- `TODO.md` — Concrete, prioritized checklist of tasks.
- `REFERENCES.md` — Links, papers, and external source material.
- `context/active/` — Primary documents actively in use.
- `context/archive/` — Historical or superseded notes.

> **Note for Small Projects**: Tiny projects use only `README.md`, `GOALS.md`, `CURRENT_STATE.md`, and `TODO.md`. Use the full suite of files only as project complexity warrants.
