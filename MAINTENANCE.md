# Maintenance Routine
Last reviewed: 2026-10-02

## Weekly
- Review active projects in `PROJECTS/ACTIVE/`.
- Update `CURRENT_STATE.md` for ongoing tasks.

## Monthly
- Archive finished projects by moving them to `PROJECTS/ARCHIVED/`.
- Delete stale context or outdated files in project `context/` folders.
- Remove duplicated knowledge from `KNOWLEDGE/`.
- Review `LEARNINGS.md` and update `MASTER_RULES.md` or prompts accordingly.

## The Golden Rule of Maintenance
If a file keeps growing and is never read, delete it or shrink it into a summary.
